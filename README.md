# Last Text at One Percent

Entry for the make.fun bounty
[Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876)
— the last text a phone sends at 1% battery, in the dying phone's own voice.

> At 1%, I confess: I deleted your 2,314 unread emails, closed ticket #1987 as
> 'cannot reproduce — battery too low', and dimmed to 3% brightness so you'd
> miss me.

One sentence, 160 characters. The phone confesses on its deathbed: it deleted
2,314 unread emails, closed a ticket with the classic "cannot reproduce", and
dimmed itself to 3% brightness — a small, petty, very human goodbye.

## Run

```bash
python3 main.py
```

This writes the entry to `/output/entry.txt` and prints it with its
character count.
